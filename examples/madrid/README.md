# Ejemplos: Madrid

## Origen de los datos

**Dataset**: Unidades Luminosas del Ayuntamiento de Madrid  
**Fuente**: [Portal de Datos Abiertos del Ayuntamiento de Madrid](https://datos.madrid.es/portal/site/egob/)  
**Año**: Vigente (actualización continua)  
**Registros**: 233.309 farolas, 491 modelos de luminaria  
**Archivo original**: `madrid-unidades-luminosas-sample.csv` (muestra de 10 filas representativas)

## Datos

El dataset de Madrid **no publica datos de centros de mando ni de consumo energético**. Solo contiene el inventario de unidades luminosas con su ubicación, modelo y tecnología. Los ejemplos complementan con datos no publicados (fabricante, poste, caja, parámetros fotométricos, propietario) para ilustrar el modelo completo.
