Energy Consumptionc back to ToC or Class ToC

IRI: https://edint.es/def/alumbrado-publico#EnergyConsumption

Observation of electricity consumption in a specific tariff period. By inheriting from edintsum:UtilityConsumption ⊂ sosa:Observation, uses the SOSA pattern: – sosa:hasFeatureOfInterest → the CentroDeMando (supply point) – sosa:observedProperty → edintsum:electricityConsumption – sosa:hasResult → qudt:QuantityValue (qudt:numericValue + qudt:hasUnit) – edintalu:tariffPeriod → SKOS concept (active, standard, off-peak, peak) Each instance represents consumption in ONE tariff period. The total is obtained by summing instances of the same fiscal year.
has super-classes
Utility Consumption c
is in domain of
tariff period op
is in range of
has consumption op

Streetlightc back to ToC or Class ToC

IRI: https://edint.es/def/alumbrado-publico#Streetlight

A complete point of light, composed of a post, one or more luminaires (which in turn contain lamps) and optionally a junction box. It is an urban element (edintinf:UrbanElement) and, by inheritance, an InfrastructureElement that can have a utility supply point (edintsum:hasUtilitySupplyPoint). Every instance of Farola has infrastructure type 'Street lamp' (edintkosinftype:StreeLamp) from the EDINT SKOS.
has super-classes
Urban Element c
is in domain of
address op, conservation status op, control center op, control method dp, data quality dp, illumination class op, illumination type op, junction box op, lighting zone op, luminaire op, number of luminaires dp, operating hours dp, post op, power supply type op, road lighting class op
