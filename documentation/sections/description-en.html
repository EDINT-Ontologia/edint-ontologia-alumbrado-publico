Public Street Lighting: Description back to ToC

Figure 1 shows the conceptual model of the ontology with its classes and relationships (object properties).

The ontology models the modular composition of a streetlight as an urban element (edintinf:UrbanElement), composed of a post (with one or more arms), one or more luminaires (each housing a lamp) and optionally a junction box.

The electrical infrastructure is represented by the control center, which is a utility supply point (edintsum:UtilitySupplyPoint) on which one or more streetlights depend. The control center may have an electricity supply contract (edintsum:UtilityContract).

Energy consumption is modeled as a SOSA observation (edintsum:UtilityConsumption ⊂ sosa:Observation), where each instance represents the consumption for a specific tariff period. The consumption value is represented via qudt:QuantityValue, expressing the magnitude through qudt:numericValue and the unit of measure through qudt:hasUnit (e.g., unit:KiloW-HR for kilowatt-hours). The tariff period is indicated by the periodoTarifario property linked to a SKOS concept (active, standard, off-peak, peak).

Street lighting classifications (support type, lamp type, conservation status, lighting zone, lighting class, etc.) are represented via object properties pointing to SKOS concepts, organized in independent concept schemes available in the kos/ folder.

The manufacturer and owner are referenceable entities (not strings), allowing them to be linked to organizations or other agents. The luminaire model serves as a catalog entry, linking manufacturer, nominal power and specifications.

The example above shows a portion of the RDF knowledge graph for a public lighting streetlight. The control center (CM-001) is the supply point on which the streetlight depends, and has an associated electricity supply contract with tariff 6.1. Energy consumption is represented as a SOSA observation: each instance (one per tariff period) has as result a qudt:QuantityValue with the numeric value and unit (kWh). The streetlight is an urban element with infrastructure type StreeLamp (EDINT SKOS), composed of a post (with its arm at 6.5 m), a luminaire (with a 72 W LED lamp) and a reference to a catalog model. Classifications (lighting type ME4b, zone E3, support type báculo, lamp type LED) are represented via SKOS concepts. The postal address reuses esdir:DireccionPostal and the geometry from GeoSPARQL.
